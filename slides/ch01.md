## 情景导入
- 手机相册自动把照片按人分组
- 背后是一个看过几百万张人脸的神经网络
- 基本零件只做三件事：**乘一乘、加一加、拐个弯**
- 本章：从一个零件讲到一个网络

::: notes
小林新买的手机有个功能：打开相册，点“人物”，几千张照片已经按人自动分好了组，连他十年前的毕业照里的自己也认了出来。他很好奇：没有人教过手机“小林长什么样”，它是怎么做到的？
手机里做这件事的，是一个神经网络。它在出厂前已经“看”过几百万张人脸，从中学会了：眼睛之间的距离、鼻子的形状、脸的轮廓……这些特征组合在一起，能把一个人和另一个人区分开。拍照时，网络把照片变成一串数字，和相册里每个人的数字比一比，最像的就归到一组。
神经网络听上去很神秘，拆开来看，它的基本零件却非常简单：每个零件只会做“乘一乘、加一加、拐个弯”这三件事。成千上万个这样的零件一层层连起来，就能认人脸、听语音、写文章。这种用很多层神经网络从数据中学习的方法，叫作深度学习。
本章从一个零件讲起：它怎样计算，为什么要“拐个弯”，很多个零件怎样连成一个网络。章末的实验里，你会在网页上亲手搭一个网络，再第一次运行 PyTorch 程序，让一个训练好的网络认出你手写的数字。
:::

## 1.1 深度学习能做什么
- 用**很多层**神经网络，直接从原始数据中学习
- 不再需要人工设计特征
- 五类任务：看图、读文字、听声音、生成、做决策
- 零件相同、训练方法相同

::: notes
深度学习是机器学习的一个分支，它用层数很多的神经网络，直接从原始数据（照片的像素、声音的波形、文章的文字）中学习规律。在深度学习出现以前，人们要先人工设计“特征”，比如告诉程序“猫的耳朵是三角形的”，再交给模型去学；深度学习把“设计特征”这一步也交给了网络自己。
今天你身边的 AI 应用，大多可以归入下面五类：
这五类任务的网络结构各不相同，但它们都由同一种零件搭成，训练方法也是同一套。本书前四章讲这套共同的“基本功”，第 5 章起再分别讲不同任务用的网络。
:::

# 1.2 从生物神经元到人工神经元

## 1.2.1 生物神经元给的启发
- 大脑约 860 亿个神经细胞
- 信号加起来够强，细胞就“兴奋”
- 1943 年：麦卡洛克和皮茨的数学模型
- 1958 年：罗森布拉特的感知机，能自动学习

::: notes
人的大脑里大约有 860 亿个神经细胞。一个神经细胞通过许多“树突”接收其他细胞传来的电信号，信号加起来足够强时，它就会“兴奋”，再通过“轴突”把信号传给下一批细胞。不同的连接强弱不同，学习的过程，在很大程度上就是这些连接变强或变弱的过程。
1943 年，麦卡洛克（McCulloch）和皮茨（Pitts）把这个过程写成了一个数学模型：几个输入，加起来超过门槛就输出 1，否则输出 0。 1958 年，罗森布拉特（Rosenblatt）又让这个模型能从例子中自动调整连接的强弱，造出了第一台能“学习”的机器——感知机。 今天的神经网络，用的仍然是这个思路。
:::

## 1.2.2 人工神经元：一张打分卡
- 例：奶茶店判断顾客会不会办会员卡
- **权重**：每条信息有多重要，加分还是减分
- **偏置**：门槛的高低
- 第一步：加权和 z = w₁x₁ + w₂x₂ + w₃x₃ + b
- 第二步：过激活函数 a = f(z)

::: notes
人工神经元（简称神经元）是神经网络的基本计算单元。可以把它想成一张“打分卡”。
假设一家奶茶店想判断一位顾客会不会办会员卡，店长看三条信息：每周来几次（x₁）、平均每次消费多少十元（x₂）、住得远不远（x₃，远为 1，近为 0）。店长心里给每条信息一个分量：来得多很重要，分量 0.6；消费高比较重要，分量 0.3；住得远是减分项，分量 −0.8。再加上一个“基础分” −1.0。这几个分量，就是神经元的权重；基础分就是偏置。
神经元做的第一件事，是算“加权和”：每个输入乘上自己的权重，全部加起来，再加上偏置。
其中 x 是输入，w 是权重，b 是偏置，z 是加权和。权重说明“每条信息有多重要、是加分还是减分”，偏置决定“门槛的高低”：偏置越小（越负），总分越难变成正数。
到这里，神经元和一个普通的“加权打分公式”没有区别。真正让它与众不同的，是下一步：把分数 z 送进一个激活函数，得到神经元的输出 a = f(z)。
:::

## 1.2.3 权重从哪里来
- 权重和偏置统称**参数**
- 不是人写的，是从数据中**训练**出来的
- 先随便给，猜错了就往“更准”的方向调

!sim neuron-activation

::: notes
上面的权重是店长凭经验给的。神经网络的权重和偏置统称参数，它们不是人写进去的，而是从数据中学出来的：先随便给一组参数，让网络对大量已知答案的例子做预测，猜错了就把参数往“猜得更准”的方向调一点，反复成千上万次。这个过程叫训练，是第 2、3 章的主题。
:::

# 1.3 激活函数：为什么要“拐个弯”

## 1.3.1 两个最常用的激活函数
- **Sigmoid**：压到 0～1，表示“把握有多大”
- **ReLU**：正数原样输出，负数变 0
- Sigmoid 常放输出层，ReLU 是隐藏层首选

::: notes
激活函数把加权和 z 变成神经元的输出 a。本书最常用的有两个：
Sigmoid 函数把任何数压到 0 到 1 之间：z 很大时输出接近 1，z 很小（很负）时输出接近 0，z = 0 时正好输出 0.5。所以它的输出可以理解为“把握有多大”。
ReLU 函数（Rectified Linear Unit，线性整流单元）更简单：z 是正数就原样输出，是负数就输出 0。
两个函数各有用处：Sigmoid 常放在网络的最后一层，输出“是某一类的概率”；ReLU 计算快、训练深层网络时效果好，是隐藏层的首选。 第 3 章会讲 ReLU 为什么让深层网络更好训练。
:::

## 1.3.1 两个最常用的激活函数

| z | −2 | −1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| Sigmoid(z) | 0.119 | 0.269 | 0.500 | 0.731 | 0.881 |
| ReLU(z) | 0 | 0 | 0 | 1 | 2 |

## 1.3.2 不“拐弯”会怎样
- h = 2x + 1，y = 3h − 4
- 接起来：y = 6x − 1，还是一层
- 没有激活函数：多少层都只能画**直线**
- 激活函数带来**非线性**，网络才能画曲线

::: notes
既然 ReLU 只是把负数变成 0，看上去没做什么，能不能干脆不要激活函数？
答案是不能。没有激活函数，每个神经元都只是“乘一乘、加一加”，这种运算叫线性运算。把两个线性运算接在一起，结果还是一个线性运算。举个例子：
所以，不管叠多少层，没有激活函数的网络都等价于一个神经元，只能画出一条直线的分界线。现实中的问题，比如“圆圈里的是一类、圆圈外的是另一类”，一条直线怎么也分不开。
激活函数在每一层之后“拐一个弯”，这种运算叫非线性。有了非线性，多层叠起来的效果就不再能合并成一层，网络才能画出弯曲的、甚至是封闭的分界线。这是神经网络能力的来源，所以说非线性必不可少。实验 1-1 里，你会亲眼看到“不用激活函数”时网络怎么训练都分不开一个圆圈。
:::

# 1.4 多层感知机与前向传播

## 1.4.1 把神经元排成层
- **输入层**：接收数据，不做计算
- **隐藏层**：中间若干层，全连接
- **输出层**：给出最后的答案
- 隐藏层越多，网络越“深”

!mermaid 1

::: notes
一个神经元只能画一条直线。把很多神经元排成几层，前一层的输出作为后一层的输入，就组成了多层感知机（Multilayer Perceptron，MLP），也叫全连接网络或前馈网络。它分三种层：
隐藏层有几层，网络就有几层“深”。今天用于图像识别的网络常有几十到上百层，大语言模型的层数也在几十层以上。“深度学习”的“深”，指的就是层数多。
:::

## 1.4.2 为什么多一层就能画出弯曲的分界线
- 每个隐藏神经元画一条直线
- 输出层把几条直线“组合”起来
- 圆圈数据：隐藏神经元 1、2、3 个
- 准确率 68.0%、84.0%、100.0%（实验 1-1）

::: notes
可以这样理解：隐藏层的每个神经元各自画一条直线，把平面分成两半；输出层再把这几条直线“组合”起来。三条直线可以围出一个三角形，更多的直线可以围出接近圆形的区域。所以，要把圆圈里外两类点分开，隐藏层至少需要 3 个神经元。实验 1-1 中，编者在网页动画里用 1 个隐藏层、ReLU 激活、训练 3000 轮，隐藏神经元为 1、2、3 个时准确率分别是 68.0%、84.0%、100.0%，正好印证了这一点。
数学上已经证明：只要隐藏层的神经元足够多，一个隐藏层的网络就能逼近几乎任何形状的分界线。 但实际中，用几层“不那么宽”的隐藏层，往往比用一层“非常宽”的隐藏层更省参数、更好训练，这也是网络越做越深的原因。
:::

## 1.4.3 前向传播：一层一层算下去
- 从输入层出发，一层层算到输出层
- 网络“使用”时做的就是一次前向传播
- 例：手机认人脸

::: notes
给网络一个输入，从输入层开始，先算出第一个隐藏层每个神经元的输出，再把它们作为下一层的输入，一层层算到输出层，这个过程叫前向传播。网络“使用”时（例如手机认人脸），做的就是一次前向传播。
1.6 节的示范例题会带你完整算一遍。
:::

# 1.5 看懂网络的“形状”

## 1.5 看懂网络的“形状”
- 最常见的错误：**形状对不上**
- 记住一句话：一层就是把“几列”变成“另外几列”

::: notes
写深度学习程序时，最常出的错就是“形状对不上”。好在只要记住一件事就够了：一层全连接网络，就是把“几列”的数据变成“另外几列”。
:::

## 1.5.1 一层就是一次“表格乘法”
- 每一行是一个样本，每一列是一个特征
- `nn.Linear(3, 4)`：进 3 列，出 4 列
- 行数不变，所有行共用同一组参数
- 参数个数：3 × 4 + 4 = 16

::: notes
把数据想成一张表：每一行是一个样本（一位顾客、一张图片），每一列是一个特征。奶茶店的数据有 3 列；一张 28 × 28 像素的手写数字图片，摊平后有 784 列。
一层“输入 3 个、输出 4 个”的全连接层，就是把每一行的 3 个数，变成 4 个新的数。不管表里有多少行，每一行都用同一组参数来算。所以：
在 PyTorch 里，这一层写作 `nn.Linear(3, 4)`，括号里正好是“进几列、出几列”。
:::

## 1.5.2 数一数参数个数
- 前一层的“出” = 后一层的“进”
- 参数个数 = 每层“进 × 出 + 出”之和
- 784 → 128 → 64 → 10：共 109 386 个

::: notes
把几层接起来，前一层的“出”必须等于后一层的“进”。参数个数就是每一层的“进 × 出 + 出”之和。
这十多万个参数都是训练出来的。今天的大语言模型有几百亿到上万亿个参数，结构比这复杂得多，但“数参数”的方法是一样的。
:::

## 1.6 示范例题
- “2 → 2 → 1”网络，隐藏层 ReLU，输出层 Sigmoid
- 输入 x = (1, 2)，求输出和参数个数
- 隐藏层：h₁ = 0.2，h₂ = 0.4
- 输出层：z = 0.3，Sigmoid 后约 **0.574**
- 参数：2 × 2 + 2 + 2 × 1 + 1 = **9** 个

::: notes
例题 一个“2 → 2 → 1”的网络，隐藏层用 ReLU，输出层用 Sigmoid。参数如下：
输入 x = (1, 2)，求网络的输出，并算出这个网络一共有多少个参数。
解题思路：前向传播，一层一层算；每个神经元都是“乘一乘、加一加、拐个弯”。
第 1 步：算隐藏层
第 2 步：算输出层
第 3 步：数参数
答：网络输出约 0.574，共 9 个参数。实验 1-2 第 5 步用 PyTorch 验证了这个结果：隐藏层输出 [0.2, 0.4]，网络输出 0.574。
举一反三：如果把输入改成 x = (0, 2)，h₁ 的 z = −0.4 + 0.1 = −0.3，ReLU 后变成 0。这时 h₁ 对输出没有任何贡献，就好像“没有被激活”，激活函数的名字就是这么来的。
:::

## 1.7 前沿视窗
- 大模型每一层：注意力 + **多层感知机**
- 多层感知机的参数常占一半以上
- 框架：PyTorch（本书）、飞桨、昇思

::: notes
大模型里也有多层感知机。今天的大语言模型几乎都基于 Transformer 结构（第 6 章介绍）。Transformer 的每一层由两部分组成：一部分是“注意力”，另一部分就是本章的多层感知机，原论文把它叫作“前馈网络”。 在很多大模型中，前馈网络的参数占全部参数的一半以上。也就是说，你在本章学到的“乘一乘、加一加、拐个弯”，正是大模型里分量最重的零件之一。
深度学习框架。早年的研究者要自己写代码实现每一步计算。今天有了深度学习框架，几行代码就能搭好一个网络。国际上最常用的是 PyTorch（本书使用）；国内有百度的飞桨（PaddlePaddle）、华为的昇思（MindSpore）等，在《人工智能开发框架技术》课程中学习。这些框架的思路相通，学会一个，另一个上手很快。
:::
