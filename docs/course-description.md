# 课程描述

**课程名称：** 神经网络与深度学习（序号 22，课程代码 5370，专业选修课，与“智能体开发”二选一）

**授课对象：** 成人教育（开放教育）人工智能技术应用专业专科学生，多为在职学习者，线上自学为主，Python 零基础起步

**学分学时：** 3 学分，54 学时 = 理论 36（其中线下 10）+ 实验 18；第 3 学期开设；过程性考核 + 期末开卷（期末占 50%）

**先修要求：** 《Python 编程》（会写变量、循环、函数，会装库、运行 .py 文件）、《人工智能数学基础》（知道向量、矩阵、导数是什么）。同学期的《机器学习》第 10–11 章讲过神经网络入门，学过更好，没学过也能读本书。

**对应证书：** 人工智能数据处理工程师（高级）、Python 技术应用工程师（高级）、人工智能应用工程师（高级）、人工智能训练师（三级）。正文用紫色“证书考点”提示框标出，详见[证书考点对照](certificate.md)。

## 课程概述

深度学习是今天大多数 AI 产品背后的技术：手机相册认人、外卖评论自动分好评差评、AI 画图、大模型聊天，用的都是多层神经网络。本课程用“先看、再跑、再改”的方式带学生认识神经网络：先用动画看清一个神经元、一层网络、一次训练在做什么，再用 PyTorch 跑通完整的“数据—训练—评估”流程，最后在图像、文本、生成和决策四类任务上各做一个小项目。

本课程坚持“会用为主、原理够用”：公式只保留最必要的几个，每个都配一个能用计算器算的小例子；反向传播只讲“误差一层层往回分摊”的直觉，求导交给框架的自动求导；Transformer 和预训练模型讲到“看懂结构图、会调用、会微调”为止。

## 主要内容

- 人工神经元、激活函数、多层感知机与前向传播
- 损失函数、梯度下降与学习率；PyTorch 张量与“训练五步”
- 反向传播的直觉、自动求导、梯度消失与常见对策、优化器
- 训练集/验证集/测试集、过拟合与欠拟合、Dropout、权重衰减、数据增强、早停、调参
- 卷积神经网络：卷积、池化、经典结构（LeNet、ResNet 等）
- 序列模型：RNN、LSTM 直觉版、注意力与 Transformer 的结构认识
- 图像分类项目与迁移学习；文本表示、词嵌入与情感分类；预训练语言模型简介
- 生成模型：自编码器、生成对抗网络、扩散模型的直觉
- 深度强化学习入门（DQN 的思路）
- 深度学习的伦理、安全与社会影响；综合项目方案设计与评审

## 不涉及的内容

- 反向传播的矩阵求导推导、手算多层网络的完整反向传播
- Python 入门语法（归《Python 编程》）
- Keras / 飞桨的系统用法、模型压缩与部署（归《人工智能开发框架技术》）
- 目标检测、分割、Stable Diffusion 的应用实战（归《计算机视觉及应用实战》）
- 分词、句法、RAG、智能体等 NLP 专题（归《自然语言处理导论》《智能体开发》）

## 学习目标（按布鲁姆认知层次）

- **记忆**：说出神经元、激活函数、损失函数、学习率、卷积核、LSTM、注意力、自编码器、GAN 等术语的含义。
- **理解**：用自己的话解释网络为什么需要非线性、训练为什么能“越来越好”、过拟合是怎么回事、CNN 为什么适合图像。
- **应用**：用 PyTorch 按“训练五步”训练一个多层感知机、一个 CNN 和一个 LSTM，并用迁移学习完成一个图像分类任务。
- **分析**：读懂训练曲线，判断过拟合或欠拟合，从混淆矩阵中找出模型常犯的错误。
- **评价**：比较 CNN、RNN、Transformer 和不同调参方案的优劣，评审一份深度学习项目方案。
- **创造**：以小组形式设计一个深度学习小项目方案，并说明数据、模型、评估和伦理风险。

## 与其他课程的关系

| 课程 | 关系 | 分工 |
|---|---|---|
| 《Python 编程》 | 先修 | 变量、循环、函数、安装库、运行程序；本书不再讲 Python 入门 |
| 《人工智能数学基础》 | 先修 | 向量、矩阵、导数的概念；本书只用到“导数是变化快慢”这一层 |
| 《机器学习》 | 并行 | 该书第 10–11 章是神经网络入门（PyTorch 与 Keras 两份代码）；本书从头讲起，但讲得更深，并完成图像、文本、生成、决策四类项目 |
| 《人工智能开发框架技术》 | 后续 | Keras、飞桨等框架的系统用法，模型保存、压缩与部署；本书只用 PyTorch 一套代码 |
| 《计算机视觉及应用实战》 | 后续 | 目标检测、图像分割、图像生成应用；本书第 5、7 章打 CNN 和迁移学习的基础 |
| 《自然语言处理导论》 | 后续 | 分词、文本表示、大模型应用与 RAG；本书第 6、8 章打 RNN、注意力和预训练模型的基础 |
