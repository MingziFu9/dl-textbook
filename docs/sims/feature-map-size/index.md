## 教学说明

**学习目标**

1. 能用公式“输出边长 = (输入边长 + 2 × 填充 − 卷积核边长) ÷ 步长 + 1”算出每层的输出形状（应用）；
2. 能算出卷积层和全连接层的参数个数，并找出“摊平后尺寸对不上”的错误（应用）。

**画面与操作**

- 上方选预设网络：实验 5-2 的 CNN、LeNet 风格、VGG 风格小网络、尺寸出错的例子，或清空后自己搭。
- 选层的类型（卷积、最大池化、摊平、全连接）并填参数，按“添加”放到网络末尾；表格列出每层的输出形状、参数个数和算式，出错的层标红。

**数据来源**：按 PyTorch 的计算规则编写。编者核对：“实验 5-2 的 CNN”共 268 650 个参数，与实验 5-2 程序打印的结果相同；LeNet 风格共 61 706 个参数，VGG 风格小网络共 106 538 个参数；“尺寸出错的例子”中摊平后是 2 048 个数，而全连接层要求 1 024 个，所以标红。

**课堂用法建议**

1. 先让学生手算实验 5-2 的 CNN 每层的形状和参数，再打开预设核对，重点看全连接层占了大部分参数。
2. 打开“尺寸出错的例子”，对照 PyTorch 报错信息 “mat1 and mat2 shapes cannot be multiplied”，练习根据报错找出哪一层的输入个数写错了。
