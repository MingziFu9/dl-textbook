## 教学说明

**学习目标**

1. 能说出梯度下降每一步怎样更新参数，解释学习率过大、过小分别会怎样（理解）；
2. 能通过对比“标准化 / 不标准化”两种情况，说明梯度下降前为什么要做特征缩放（分析）。

**画面与操作**

- 左图是均方误差随 w、b 变化的地形图，颜色越浅损失越小，橙色 ★ 是最低点；红色折线是参数走过的路。
- 右图是 5 套房子和当前参数对应的直线，虚线是每套房子的误差。
- “走一步”“连走 20 步”“连走 200 步”执行梯度下降；换学习率或换模式会回到起点 (0, 0)。
- 上方可以切换面积是否标准化。标准化时地形是圆形的山谷；不标准化时山谷又窄又长。

**数据来源**：3.2.3 节手算用的 5 套房子（面积 50、70、90、110、130 平方米，总价 160、210、250、320、360 万元）。最低点和各学习率的结果与实验 3-1 的输出一致：标准化后学习率 0.1 和 0.9 在第 20 步的损失相同，1.05 发散；不标准化时学习率 0.0001 走 200 步损失约 121，0.0002 发散。

**课堂用法建议**

1. 标准化模式下依次试学习率 0.01、0.1、0.9、1.05，请学生描述四条路径的区别，对应“太小、合适、偏大、太大”。
2. 切换到不标准化，试 0.0001 和 0.0002，引导学生发现“没有一个学习率能同时照顾 w 和 b”，再回到第 2 章的特征缩放。
3. 让学生预测“学习率 0.5 走一步能不能直接到达谷底”，再验证（标准化后 Hessian 是 2 倍单位矩阵，学习率 0.5 一步到位）。
