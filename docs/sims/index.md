# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。

| 章 | 动画 | 你可以做什么 |
|---|---|---|
| 第 1 章 | [神经元与激活函数](neuron-activation/index.md) | 勾选输入、拖动权重和偏置，看神经元怎样加权求和再过激活函数；看感知机为什么学不会异或 |
| 第 1 章 | [网络游乐场](nn-playground/index.md) | 选数据、隐藏层和激活函数，看网络怎样画出分界线，找出最少需要多大的网络 |
| 第 2 章 | [梯度下降下山](gradient-descent/index.md) | 在损失的“地形图”上选学习率，一步步看梯度下降怎样走到最低点 |
| 第 3 章 | [误差往回传](backprop-flow/index.md) | 在一个神经元的计算图上前向、反向、更新，看梯度怎样往回传、损失怎样变小 |
| 第 4 章 | [训练曲线诊断器](curve-doctor/index.md) | 看四组真实训练曲线，判断欠拟合、过拟合、学习率太大还是健康 |
| 第 5 章 | [卷积计算器](conv-calculator/index.md) | 让 3×3 卷积核一格一格滑动，看“相乘再相加”；改步长、填充，做最大池化 |
| 第 5 章 | [CNN 尺寸与参数计算器](feature-map-size/index.md) | 往网络里加层，自动算出每层输出形状和参数个数，找出尺寸对不上的层 |
| 第 6 章 | [RNN 与 LSTM 逐步展开](rnn-lstm/index.md) | 一个词一个词地读句子，比较简单 RNN 和 LSTM 谁能记住开头的词 |
| 第 6 章 | [自注意力热力图](self-attention/index.md) | 看句子里每个词在“注意”哪些词，体会“它”怎样找到指代对象和掩码的作用 |
| 第 7 章 | [冻结几层好](freeze-layers/index.md) | 选择解冻最后几层，看要训练的参数和验证准确率的真实变化 |
| 第 8 章 | [词向量与余弦相似度](word-vectors/index.md) | 拖动向量体会余弦相似度，在词语地图上找近义词、做类比 |

其中“神经元与激活函数”“梯度下降下山”“卷积计算器”与《机器学习》共用，“训练曲线诊断器”“冻结几层好”的数据来自《人工智能开发框架技术》的实际训练记录，“自注意力热力图”“词向量与余弦相似度”与《自然语言处理导论》共用。每个动画的说明页都写明了数据来源和对应本书的哪一节。
