## 教学说明

**学习目标**

1. 能手算一个位置的卷积结果，说出步长、填充对特征图尺寸的影响（应用）；
2. 能解释竖边、横边、模糊、锐化四种卷积核各自“找”的是什么，以及最大池化的作用（理解）。

**画面与操作**

- 左边是输入图，数字是像素亮度，点格子可以在 0 和 1 之间切换；中间是卷积核；右边是特征图。橙框是当前位置，下方写出完整的乘加算式。
- 选输入图（左暗右亮、十字、上暗下亮、斜线）和卷积核（竖边、横边、模糊、锐化），选步长 1 或 2、填充 0 或 1；“下一个位置”逐格计算，“全部算完”一次算完；“2×2 最大池化”逐格显示池化结果。

**数据来源**：示意数据。编者核对：“左暗右亮”5×5 图配竖边卷积核时，步长 1 填充 0、步长 1 填充 1、步长 2 填充 1 三种情况的特征图与实验 11-1 用 NumPy 算出的完全相同；“十字”图配模糊卷积核的结果与 NumPy 相同。

**课堂用法建议**

1. 先让学生在纸上算“左暗右亮”配竖边核的第一个位置，再点“下一个位置”核对；问：为什么右边一列是 0？
2. 切到填充 1，观察特征图变成 5×5，最右一列出现 −3：补的 0 在图的边上造出了一条“假边”。
3. 换成“上暗下亮”，比较竖边核和横边核的输出，体会“一个卷积核只找一种图案”。
