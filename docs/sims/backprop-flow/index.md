## 教学说明

**学习目标**

1. 能按计算图从损失出发，逐步算出每个量的梯度（应用）；
2. 能说出 Sigmoid 的导数最大只有 0.25，并解释它为什么会让梯度变小（理解）。

**画面与操作**

- 设置输入 x、权重 w、偏置 b、目标 y，选择激活函数（不用、Sigmoid、ReLU）和学习率。
- 依次按“① 前向”“② 反向”“③ 更新一步”：蓝色数字是前向算出的值，红色数字是反向算出的梯度；下方表格记录每一步的 w、b、损失和两个梯度。也可以按“自动走 10 步”。

**数据来源**：示意数据。计算图为 z = w·x + b，a = f(z)，L = (a − y)²。默认数值与 3.2.2 节相同：x = 2、w = 0.5、b = 0、y = 3、不用激活函数，前向得 L = 4，反向得 dL/dw = −8、dL/db = −4；学习率 0.05 更新一步后 w = 0.9、b = 0.2，损失降为 1。

**课堂用法建议**

1. 先让学生在纸上算出默认数值的两个梯度，再按“② 反向”核对。
2. 把激活函数换成 Sigmoid，比较 dL/dw 变小了多少，为 3.4 节的梯度消失做铺垫。
