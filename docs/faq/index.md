## 课程与学习方法 { #faq-1 }

??? question "数学不好，能学这门课吗？"

    能。本书只用到“导数表示变化快慢”这一层数学，公式只保留最必要的几个，每个都配了用计算器就能算的小例子（各章的“算一算”和示范例题）。求导这件事交给 PyTorch 的自动求导完成，见 [3.3 节](../chapters/03-backprop/index.md#33)。

??? question "这门课和《机器学习》第 10–11 章有什么不同？"

    《机器学习》用两章介绍神经网络入门；本书从头讲起，但讲得更深：训练过程（第 2–4 章）、CNN 与序列模型（第 5–6 章），再在图像、文本、生成、决策四类任务上各做一个小项目。没学过《机器学习》也能读本书。见[课程描述](../course-description.md)。

??? question "为什么只用 PyTorch？Keras、飞桨还要学吗？"

    一门课只学一个框架，精力集中在“网络怎么搭、怎么训练”上。PyTorch 是目前研究和开源模型用得最多的框架。Keras 和飞桨在《人工智能开发框架技术》中系统学习，有了本书的基础，换一个框架只是换写法。

??? question "书上标着“待实测”的实验是什么意思？"

    本书只有实验 8-3（中文预训练模型微调）标为“待实测”：它要从网上下载约 150 MB 的预训练模型，编者的编写环境下载不了，所以没有给出运行结果，而是附了一张记录表，请你运行后自己填写。详见[附录 B](../appendix/b-environment.md)。

??? question "每章实验这么多，都要做吗？"

    不用。每章的实验多于实验学时能做完的数量，★ 是基础实验，☆ 是拓展实验，由老师任选；没做的可以作为课后练习。每章开头的“本章实验”表写明了每个实验的用时。

## 基本概念 { #faq-2 }

??? question "深度学习、机器学习、人工智能是什么关系？"

    一个套一个：人工智能是大目标，机器学习是实现它的主要办法（让计算机从数据中学规律），深度学习是机器学习中用多层神经网络的那一类方法。见 [1.1 节](../chapters/01-neuron/index.md#11)。

??? question "为什么一定要有激活函数？"

    没有激活函数，每一层都只是“乘权重再相加”，多少层叠起来都能合并成一层，只能画直线分界线。激活函数让每一层“拐个弯”，网络才能画出弯曲的分界线。实验 1-1 能亲眼看到这一点。见 [1.3 节](../chapters/01-neuron/index.md#13)。

??? question "反向传播和梯度下降是一回事吗？"

    不是一回事，但总是一起用。反向传播负责“算出每个参数的梯度”（误差怎样往回分摊），梯度下降负责“按梯度把参数调一小步”。见 [3.2 节](../chapters/03-backprop/index.md#32)和 [2.2 节](../chapters/02-training/index.md#22)。

??? question "CNN 为什么比全连接网络更适合图像？"

    两个原因：卷积核在整张图上共用同一组权重，参数少得多；卷积核只看一小块相邻的像素，保留了位置关系。实验 5-2 中，CNN 参数只有全连接网络的约三分之一，准确率却从 46.7% 提高到 63.3%。见 [5.1 节](../chapters/05-cnn/index.md#51)、[5.2 节](../chapters/05-cnn/index.md#52)。

??? question "有了 Transformer，RNN 和 LSTM 还有用吗？"

    有。长文本、大数据、要并行训练时，Transformer 更强；数据少、序列短、设备算力有限时，LSTM 往往够用而且更快。实验 6-3 预测气温时，两者误差几乎一样，LSTM 还快 3 倍。见 [6.6 节](../chapters/06-sequence/index.md#66)。

??? question "迁移学习为什么能“借”别人的模型？"

    在大量图片上训练过的网络，前面几层学到的是边缘、纹理、形状这些通用特征，换一个任务照样有用，只需要重新训练最后几层。实验 7-2 中，只训练最后一层（5130 个参数），准确率就从自己从头训练的 59.3% 提高到 88.4%。见 [7.3 节](../chapters/07-image-transfer/index.md#73)。

??? question "GAN 和扩散模型有什么区别？"

    GAN 用两个网络比赛：生成器造假，判别器鉴定，一次就生成一张图，速度快但训练不稳定。扩散模型先学“一点点去噪声”，生成时从纯噪声出发一步步去噪，速度慢但效果稳定，是今天 AI 画图的主流。见 [9.3 节](../chapters/09-generative/index.md#93)、[9.4 节](../chapters/09-generative/index.md#94)。

## 训练与调参 { #faq-3 }

??? question "训练集准确率很高，测试集却很低，怎么办？"

    这是过拟合。可以依次试：加数据增强、加 Dropout、加权重衰减、用早停，或者换成迁移学习。实验 4-2 比较了这几种办法的效果。见 [4.2 节](../chapters/04-generalization/index.md#42)、[4.3 节](../chapters/04-generalization/index.md#43)。

??? question "损失一直不下降，或者变成 nan，是怎么回事？"

    最常见的原因是学习率太大，先把学习率缩小 10 倍再试；其次检查输入有没有标准化、标签是不是对应正确。见 [2.2.2 节](../chapters/02-training/index.md#222)和 [4.5 节](../chapters/04-generalization/index.md#45)。

??? question "学习率、批大小、轮数，先调哪个？"

    先调学习率（影响最大），再调网络大小和正则化，最后调批大小；轮数交给早停决定。每次只改一个设置，并把结果记在调参记录里。见 [4.5 节](../chapters/04-generalization/index.md#45)和实验 4-3。

??? question "为什么每次运行结果都有一点不一样？"

    网络的初始权重、数据打乱的顺序都是随机的。本书的程序都固定了随机种子，同一台电脑上结果可以重复；换电脑、换 PyTorch 版本后，最后一两位小数可能不同，这是正常的。

??? question "验证集和测试集有什么区别？能不能只要一个？"

    验证集用来挑选设置（调参、早停），会被反复“看”；测试集只在最后用一次，用来给出公正的成绩。只用一个的话，挑出来的设置会“偏向”这份数据，成绩偏高。见 [4.1 节](../chapters/04-generalization/index.md#41)。

## 实验环境与排错 { #faq-4 }

??? question "没有显卡能做实验吗？"

    能。除实验 8-3 外，本书所有编程实验都在 4 核 CPU、无显卡的电脑上实测过，大多数几分钟内就能跑完。实验 8-3 和第 10 章的项目如果数据较大，可以用附录 B 介绍的云算力平台。详见[附录 B](../appendix/b-environment.md)。

??? question "安装 PyTorch 很慢或者失败，怎么办？"

    用国内镜像安装，例如在 pip 命令后面加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`；没有显卡的电脑装 CPU 版即可，体积小很多。详见[附录 B](../appendix/b-environment.md)。

??? question "第一次运行时下载数据集失败，怎么办？"

    程序会把数据下载到 `labs/data/` 目录。网络不好时，可以按附录 B 列出的地址在浏览器中手动下载，放到 `labs/data/` 下对应的位置，再运行程序就不会重复下载。详见[附录 B](../appendix/b-environment.md)。

??? question "报错 `mat1 and mat2 shapes cannot be multiplied` 是什么意思？"

    全连接层要求的输入个数和实际送来的个数对不上，通常是改了卷积层或池化层，`nn.Linear` 的第一个参数没跟着改。逐层打印形状就能找到。见 [5.5 节](../chapters/05-cnn/index.md#55)和动画[CNN 尺寸与参数计算器](../sims/feature-map-size/index.md)。

??? question "图上的中文显示成方框，怎么办？"

    这是 Matplotlib 没找到中文字体。本书程序会依次尝试黑体、微软雅黑、苹方、文泉驿、Noto Sans CJK 等常见中文字体；如果仍是方框，按附录 B 的说明安装一个中文字体（如 Noto Sans CJK）。详见[附录 B](../appendix/b-environment.md)。

??? question "报错 `No module named 'xxx'`，怎么办？"

    缺少这个工具库。在 `labs/` 目录下运行 `pip install -r requirements.txt`，一次装好本书用到的全部库。

??? question "程序跑得很慢，能不能先少跑一点？"

    能。各实验程序中训练的轮数写在 `epochs=` 后面，改小后结果会差一些，但足以看清趋势；课堂上可以先用小设置演示，课后再跑完整版本。
