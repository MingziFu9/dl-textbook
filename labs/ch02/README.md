# 第 2 章 训练的本质：损失函数与梯度下降：实验代码

对应教材：[第 2 章](https://mingzifu9.github.io/dl-textbook/chapters/02-training/)。所有程序都在 `labs/` 目录下运行，例如：

```bash
cd labs
python ch02/lab2_1_line_fit.py
```

| 实验 | 类型 | 用时 | 内容 | 程序 |
|---|---|---|---|---|
| 2-1 | ★ 基础 | 30 分钟 | 用梯度下降拟合广告费与销量的直线，体会“训练五步”和损失曲线 | `lab2_1_line_fit.py` |
| 2-2 | ★ 基础 | 45 分钟 | 从零训练多层感知机识别手写数字：准备数据、搭网络、训练五步、评估、保存 | `lab2_2_mnist_mlp.py` |
| 2-3 | ☆ 拓展 | 30 分钟 | 改学习率和批大小，比较训练效果，填写记录表 | `lab2_3_lr_batch.py` |

程序运行时生成的图片（`.png`）和模型文件（`.pt`）保存在本目录，不提交到仓库。数据第一次使用时自动下载到 `labs/data/`，见 `labs/data/README.md`。
