# 第 10 章 深度强化学习、伦理与综合项目：实验代码

对应教材：[第 10 章](https://mingzifu9.github.io/dl-textbook/chapters/10-drl-project/)。所有程序都在 `labs/` 目录下运行，例如：

```bash
cd labs
python ch10/lab10_1_dqn_cartpole.py
```

| 实验 | 类型 | 用时 | 内容 | 程序 |
|---|---|---|---|---|
| 10-1 | ★ 基础 | 40 分钟 | 运行 DQN 程序，看一个小网络怎样学会平衡小车，读得分曲线 | `lab10_1_dqn_cartpole.py` |
| 10-2 | ★ 基础 | 课余 2～3 周 + 线下 2 学时 | 小组综合项目：写方案、做原型、线下汇报互评 | 无需编程 |

实验 10-2 是小组项目，没有统一的程序；项目方案模板和评分表见教材 10.4 节。

程序运行时生成的图片（`.png`）和模型文件（`.pt`）保存在本目录，不提交到仓库。数据第一次使用时自动下载到 `labs/data/`，见 `labs/data/README.md`。
