# 第 1 章 初识神经网络：从一个神经元说起：实验代码

对应教材：[第 1 章](https://mingzifu9.github.io/dl-textbook/chapters/01-neuron/)。所有程序都在 `labs/` 目录下运行，例如：

```bash
cd labs
python ch01/lab1_2_first_run.py
```

| 实验 | 类型 | 用时 | 内容 | 程序 |
|---|---|---|---|---|
| 1-1 | ★ 基础 | 20 分钟 | 在网页动画“网络游乐场”里搭网络，把四组数据的两类点分开，找出“最少需要多大的网络” | 无需编程 |
| 1-2 | ★ 基础 | 25 分钟 | 安装 PyTorch，运行现成程序：看网络结构、在 1 万张测试图片上考一考、认一认你手写的数字，再验证 1.6 节的示范例题 | `lab1_2_first_run.py` |

`mnist_mlp.pt` 是编者训练好的手写数字模型（由 `train_demo_model.py` 训练生成，学生不用运行），`my_digit.png` 是一张手写数字示例图，实验 1-2 直接使用。

程序运行时生成的其他图片和模型文件保存在本目录，不提交到仓库。数据第一次使用时自动下载到 `labs/data/`，见 `labs/data/README.md`。
